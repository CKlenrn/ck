# Po0GZ Traffic Surge

Surge iOS module for the Po0 service **腾讯云广州 - Spring Special** (service ID 4040).

## Install

Add this module URL to Surge:

https://raw.githubusercontent.com/CKlenrn/ck/main/surge/po0-traffic/po0-traffic.sgmodule

When enabling it, fill in the Po0 console email and password in the module parameters. The module displays upload, download, and remaining traffic in a dynamic panel. It does not call the firewall whitelist endpoint and does not include credentials.
